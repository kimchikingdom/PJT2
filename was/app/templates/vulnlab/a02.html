A02 – Security Misconfiguration

기본값 SECRET_KEY 사용, 상세 오류 메시지 노출 등 보안 설정 오류를 시연합니다.

⚠ 교육 목적으로 의도적으로 구현된 취약점입니다.
{% endblock %} {% block content %}

현재 설정 정보 노출

설정 키 값 위험
SECRET_KEY {{ secret_key }} HIGH
DEBUG {{ debug_mode }} MEDIUM
DATABASE_URL {{ db_url }} HIGH

상세 오류 메시지 노출

?trigger_error=1을 추가하면 ZeroDivisionError의 전체 traceback이 노출됩니다.

오류 발생 시킴 (취약) {% if error_detail %}
노출된 Traceback: 
{{ error_detail }}
{% endif %}

❌ 취약한 설정

# config.py
SECRET_KEY = "dev-secret"  # 기본값!
DEBUG = True               # 운영 환경에서도 켜짐

# 오류 핸들러 없음 → 전체 traceback 노출

✅ 안전한 설정

# 환경 변수에서 주입
SECRET_KEY = os.environ["SECRET_KEY"]
DEBUG = False

@app.errorhandler(500)
def server_error(e):
    log.error(e)  # 내부 기록만
    return "서버 오류가 발생했습니다.", 500
