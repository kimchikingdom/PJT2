인증 실패 – 순차 세션 ID 추측 공격

session_id=1, 2, 3 처럼 예측 가능한 세션 값을 발급하면 로그인 없이 타인의 세션을 탈취합니다.

교육 목적으로 의도적으로 구현된 취약점입니다.
{% endblock %} {% block content %}

단계 1: 취약한 앱에 로그인 (순차 세션 ID 발급)

사용자명을 입력하면 session_id=1, 2, 3... 처럼 예측 가능한 정수 ID가 발급됩니다.

{% if session_info %}
발급된 세션 정보:
{{ session_info.session_id }}
Set-Cookie: session_id={{ session_info.session_id }}
username: {{ session_info.user.username }}
role: {{ session_info.user.role }}
→ 공격자는 이 값 ±1 을 추측해서 로그인 없이 다른 사용자로 접근 가능!
{% endif %}

단계 2: 현재 발급된 세션 목록

{% for sid, user in sessions.items() %} {% endfor %}
session_id username role 세션 탈취
{{ sid }} {{ user.username }} {{ user.role }} /profile?session_id={{ sid }}
{% endif %}

단계 3: 세션 ID 직접 추측 (공격자 시점)

브라우저 주소창에서 직접 아래 URL을 입력하세요. 로그인 여부와 관계없이 해당 세션의 사용자 정보가 표시됩니다.

http://localhost:8080/vulnlab/auth2/profile?session_id=1
{% for i in range(1, [sessions|length + 1, 6]|min) %} session_id={{ i }} {% endfor %}

취약한 세션 발급

# 단순 카운터 세션 ID
counter += 1
session_id = counter   # 1, 2, 3, 4...

resp = make_response(redirect("/home"))
resp.set_cookie("session_id",
                str(session_id))  # 예측 가능!

안전한 세션 발급

import secrets

# 암호학적으로 안전한 랜덤 토큰
session_token = secrets.token_urlsafe(32)
# 예: "3d9Xk-mQr8vBcZ1..."  (256bit)

resp = make_response(redirect("/home"))
resp.set_cookie("session", session_token,
                httponly=True,
                secure=True,
                samesite="Strict")
