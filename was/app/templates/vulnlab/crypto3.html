취약한 파일 다운로드 URL 설계

다운로드 URL에 파일명이 그대로 노출되며, 파일명 자체에 환자 이름과 생년월일이 포함됩니다. 소유권 체크가 없어 URL의 파일명만 변경하면 타인의 의료 기록에 접근할 수 있습니다.

로그인한 사용자의 정상 다운로드 링크:
GET /vulnlab/crypto3/download?file_name={{ my_file }}
내 파일 다운로드 (정상)
⚠ URL 파일명 변조 → 타인의 의료 기록 탈취 (IDOR 공격)

직접 URL 조작 시연

브라우저 주소창에서 file_name 값을 아래 파일명으로 직접 변경해보세요.

http://localhost:8080/vulnlab/crypto3/download?file_name=진료기록_김철수_850315.pdf
→ 로그인한 사용자가 누구든 관계없이 김철수의 진료 기록이 다운로드됩니다.

❌ 취약한 설계

# URL에 개인정보 포함된 파일명
# /download?file_name=진료기록_홍길동_900101.pdf

@app.route("/download")
@login_required
def download():
    name = request.args.get("file_name")
    # ❌ 소유권 체크 없음!
    return send_file(f"./reports/{name}")

✅ 안전한 설계

# UUID로 파일 식별 (개인정보 제거)
# /download/a1b2c3d4-...

@app.route("/download/")
@login_required
def download(file_id):
    record = FileRecord.query.get_or_404(file_id)
    # ✅ 소유권 체크
    if record.owner_id != current_user.id:
        abort(403)
    return send_file(record.stored_path,
        download_name=record.display_name)
